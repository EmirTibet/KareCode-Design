TUI (Text-based User Interface / Metin Tabanlı Arayüz):
Yine terminalde çalışır ama CLI'dan farklı olarak etkileşimli, görsel düzenli bir ekran sunar.
Menüler,kutucuklar,çerçeveler,renkli paneller içerebilir.Ekran anlık olarak güncellenir, sabit durmaz

GUI (Graphical User Interface / Grafik Arayüz):
GUI, pencere, buton ve ikon gibi görsel öğelerle fare/dokunma yoluyla kullanılan, tamamen grafiksel arayüzdür.


CLI – TUI – GUI Arasındaki Farklar:

CLI: Sadece yazılı komutlarla, klavye ile kullanılır,Görsel öğe yok, sadece düz metin satırları alt alta birikir.

TUI:Klavye ile menüler/panolar arasında gezinerek kullanılır.Terminal içinde ama düzenli görsel yapısı vardır

GUI:Fare ile buton, ikon, pencerelere tıklayarak kullanılır,diğerlerine göre daha kolaydır görsele dayalı bir arayüzdür.
