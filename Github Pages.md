GitHub Pages Nedir?

GitHub Pages, GitHub üzerinde bulunan depolardaki (repository) HTML, CSS ve JavaScript gibi statik web dosyalarını ücretsiz olarak internette yayınlamayı sağlayan bir hosting hizmetidir.

Herhangi bir sunucu kiralamaya veya harici bir hosting hizmeti satın almaya gerek kalmadan projelerin çevrim içi erişilebilir hâle getirilmesini sağlar.

GitHub Pages, bir GitHub deposuna bağlanarak çalışır ve belirlenen kaynak dalındaki (branch) veya klasördeki dosyaları kullanarak web sitesini otomatik olarak yayınlar. 
 
Projede yapılan değişiklikler GitHub'a gönderildikten sonra (push) GitHub Pages tarafından yeniden dağıtılabilir.
