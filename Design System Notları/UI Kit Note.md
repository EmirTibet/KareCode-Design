UI Kit, bir tasarım aracında (Figma) hazır duran görsel bileşenlerdir.Siteyi yaparken karar verdiğin UI kit, birden fazla geliştiricinin olduğu projelerde yol gösterici olur.Geliştiriciler bu kitin dışına çıkmazlar.

UI Kit'in Bileşenleri (components);
1. Buton
2. Input (Giriş Alanı)
3. Checkbox / Radio Button
4. Dropdown (Açılır Menü)
5. Badge / Etiket
6. Card (Kart)
7. Navigation Bar (Menü Çubuğu)
8. Modal / Popup
9. Icon
